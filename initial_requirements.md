### Initial Requirements
- This is a collection of CAD artifacts, images, and text-based assembly instructions. 
- They describe the individual components of a tool that extends earlier work to  provide support for Raspberry Pi - based ground magnetometer.
- The intent is to data to make earlier hardware useful using other computing devices such as Beelink (and other) NUC-style computers and standard laptops.
- The goal is to continue to use proven data collection hardware to meet the evolving needs of a growing set of project objectives.
- This project attempts to document the process of assembling the hardware and software components to acheive a variety of objectives.

### Top level objectives:
- present the Cad artifacts required in an Open format to allow other investigators to recreate this work.
- provide a set of instructions to assemble the hardware and software components.
- provide a set of instructions to install the software components.
- provide a set of instructions to configure the software components.
- to provide the necessary information to deploy this hardware into field situations for its intended purposes.

### Creating the setup from scratch
While many users may chose to purchase assembled or partly-assembled kits from sources such as the TAPR store, the intent here is to provide all information necessary to fabricate and assemble this project from scratch for modification and ebellishment to meet unique needs.
Included material.
- CAD artifacts
- Images
- Text-based assembly instructions
- Photos or diagrams of these units in use in tupicla scenarios.
