Contributing
============

Contributions to the Pi-Eliminator project are welcome!

How to Contribute
-----------------

1. **Report Issues**: Use the GitHub issue tracker to report bugs or suggest enhancements.
2. **Submit Pull Requests**: Fork the repository, make your changes, and submit a pull request.
3. **Documentation**: Help improve the documentation by editing the files in the `docs/` directory.

Code of Conduct
---------------

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. (See `CODE_OF_CONDUCT.md` in the root directory).
