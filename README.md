# pi-eliminator

Hardware design for the Pi-Eliminator, a component of the Personal Space Weather Station (PSWS) project.
Official documentation for this project can be found at [pi-eliminator-github](https://pi-eliminator-github.readthedocs.io/).
## Overview

The Pi-Eliminator is designed to interface with SDR hardware, specifically related to the ClementineSDR and projects involving the LTC2208 ADC. It appears to serve as an interface or replacement for Raspberry Pi-based setups in these systems, featuring standard 2x20 pin headers.

## Project Structure

- `pi-eliminator-github.kicad_sch`: Schematic file.
- `pi-eliminator-github.kicad_pcb`: PCB layout file.
- `production/`: Manufacturing files (BOM, Gerbers, etc.).
- `Local Resources/`: Datasheets, design notes, and reference bitmaps.
- `docs/`: Documentation for ReadTheDocs.
